Sobre o Curso

Domine a linguagem mais popular do mundo

Python é a linguagem de programação mais utilizada no mundo, sendo essencial para áreas como Inteligência Artificial, Ciência de Dados, Automação e Desenvolvimento Web.

Este curso foi criado para quem nunca programou antes. Você vai aprender desde os fundamentos até a criação de projetos completos, sempre com exemplos práticos.

  • Sintaxe e fundamentos do Python
  • Variáveis, tipos de dados e operadores
  • Estruturas de decisão e repetição
  • Funções e modularização
  • Listas, dicionários e manipulação de dados
  • Projetos práticos para portfólio

Módulo 1

  • Instalação e configuração

Projetos Práticos
